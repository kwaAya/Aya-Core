# Domain Migration

The canonical domain in this repository is `https://ayacorestudios.netlify.app`.

The retired Netlify deployments cannot be configured from this workspace. Apply
the following redirects in each retired site's Netlify deploy settings, or add
this `_redirects` file to the retired site's deployed output:

```text
https://ayacore.netlify.app/* https://ayacorestudios.netlify.app/:splat 301!
https://ayacreativestudios.netlify.app/* https://ayacorestudios.netlify.app/:splat 301!
```
